SOBRE EL PROYECTO

Comprender las vulnerabilidades

Este sitio explica de forma sencilla qué son las vulnerabilidades CVE, cómo se identifican y por qué las actualizaciones son una parte fundamental de la defensa.

¿Qué significa CVE?

CVE significa Common Vulnerabilities and Exposures. Es un sistema de identificación utilizado para referirse de manera consistente a vulnerabilidades de seguridad conocidas.

Un CVE no significa que el problema pertenezca a HTML, redes o un único tipo de tecnología. Puede corresponder a navegadores, sistemas operativos, aplicaciones, dispositivos de red, servidores y otros productos.

¿Qué es NVD?

La National Vulnerability Database (NVD) del NIST proporciona información sobre vulnerabilidades, incluyendo referencias, productos afectados, debilidades CWE y métricas de riesgo cuando existen datos suficientes.

Para este proyecto se consultaron registros publicados durante septiembre de 2026.

Los tres casos presentados

1. CVE-2026-85046 — Chrome / V8

NVD registra una confusión de tipos en V8. La vulnerabilidad afecta versiones de Chrome anteriores a 152.0.7977.82 y puede ser activada mediante una página HTML especialmente creada. Google indicó que existía explotación en la práctica.

2. CVE-2026-87886 — Acronis Backup

Se trata de una escalada local de privilegios causada por permisos de archivos inseguros. Afecta determinados complementos/extensiones de Acronis Backup para Linux. Las versiones corregidas deben verificarse en el aviso del fabricante.

3. CVE-2026-58704 — Android / Cellular Modem

Google describe un bypass de permisos debido a un error lógico en el componente Cellular Modem. El registro indica posibilidad de escalada de privilegios desde un vector de red adyacente y sin interacción del usuario.

Conceptos clave

  • CVE: identificador de vulnerabilidad.
  • CWE: clasificación del tipo de debilidad.
  • CVSS: sistema de puntuación de severidad.
  • CPE: identificación estandarizada de productos.
  • KEV: catálogo de vulnerabilidades conocidas como explotadas de CISA.
